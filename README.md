# PPC System — Production Planning & Control

Garment factory workflow tracker — 5 PPC forms based.

## Features
- Team Layout Plan (PPC-02)
- Operation Allocation Plan (PPC-03)
- Operator Daily Output + Downtime Log
- Initial Quality Report (PPC-04)
- Final Quality Report (PPC-05)
- Auto calculations (Defect Rate, True Cost of Poor Quality)
- Operator Performance Score
- Role-based dashboards with charts

## Tech Stack
- Django 6.1
- SQLite (dev) / PostgreSQL (prod)
- Bootstrap 5
- Chart.js

## Roles
- Admin — full access + Django Admin
- Supervisor — team management
- QC — quality reports
- Operator — output + downtime
